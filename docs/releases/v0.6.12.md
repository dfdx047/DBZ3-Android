## PT
**Dragon Fury 0.6.12 — Turnip no Adreno 6xx, novo menu do jogo e logs completos**

Primeira versão pública desde a 0.3.0. Os destaques:

- **Turnip no Adreno 6xx** (Snapdragon 865/855/480+, ex. Retroid Pocket 5): o jogo agora roda com o Turnip, com imagem completa (cenários, lutadores, HUD, menus e vídeos). Antes saía sem texturas e a GPU travava. Nesses aparelhos o driver do sistema continua sendo o padrão (é o mais rápido hoje); o Turnip fica na aba Drivers com a opção "Usar o Turnip mesmo assim".
- **Compatibilidade automática do Turnip**: se a GPU travar com um driver Turnip, o próximo arranque passa sozinho para um modo mais seguro, e o launcher explica o que aconteceu.
- **Menu do jogo novo**, com abas (Jogo, Vídeo, Efeitos, Áudio, Controles, Depuração), controlado pelo controle (LB/RB trocam de aba, A confirma, B volta) ou por toque. Abre com Voltar ou Select + Start.
- **Launcher**: barra de abas embaixo com ícones, botões das redes nas cores de cada uma, filtro **Bilinear** por padrão (o FSR custava muita GPU).
- **Logs de tudo** o que o app faz e janelas de erro que explicam o problema, com botão para salvar o log em Downloads. Quando o jogo fecha com erro (crash, memória, travamento, GPU) o launcher diz porquê.
- **Aviso de processador**: em chips ARMv8.0 (Snapdragon 665/660/835…) o launcher avisa em vez de fechar na hora.
- **Desempenho**: cortes de trabalho de GPU vindos do Dragon Burst, resoluções **540p** e **360p**, **120 FPS interpolado** em telas de 120 Hz e preset automático para Mali (540p, efeitos desligados).
- **Importação** direto da ISO do Xbox 360 (XGD2/XGD3/XISO), mais rápida.
- **Autoteste do render** no menu do jogo, para diagnosticar problemas de imagem e desempenho.

Driver do sistema (Adreno) e Mali: sem mudanças de comportamento nesta versão; as correções do Turnip só valem com o Turnip num Adreno 6xx.

## EN
**Dragon Fury 0.6.12 — Turnip on Adreno 6xx, new in-game menu and full logs**

First public release since 0.3.0. Highlights:

- **Turnip on Adreno 6xx** (Snapdragon 865/855/480+, e.g. Retroid Pocket 5): the game now runs on Turnip with a complete picture (stages, fighters, HUD, menus and videos). Before, textures were missing and the GPU crashed. On these devices the system driver is still the default (it is the fastest today); Turnip is in the Drivers tab with "Use Turnip anyway".
- **Automatic Turnip compatibility**: if the GPU crashes with a Turnip driver, the next start switches to a safer mode by itself, and the launcher explains what happened.
- **New in-game menu** with tabs (Game, Video, Effects, Audio, Controls, Debug), driven by controller (LB/RB switch tabs, A confirms, B goes back) or touch. Opens with Back or Select + Start.
- **Launcher**: bottom tab bar with icons, community buttons in each network's colors, **Bilinear** upscaling by default (FSR cost a lot of GPU time).
- **Logs for everything** the app does and error windows that explain the problem, with a button to save the log to Downloads. When the game closes with an error (crash, memory, freeze, GPU) the launcher tells you why.
- **CPU check**: on ARMv8.0 chips (Snapdragon 665/660/835…) the launcher explains it instead of closing instantly.
- **Performance**: GPU work cuts ported from Dragon Burst, **540p** and **360p** resolutions, **120 FPS interpolated** on 120 Hz screens and an automatic Mali preset (540p, effects off).
- **Import** straight from the Xbox 360 ISO (XGD2/XGD3/XISO), faster.
- **Render self-test** in the in-game menu, to diagnose picture and performance problems.

System driver (Adreno) and Mali: no behavior changes in this release; the Turnip fixes only apply to Turnip on Adreno 6xx.

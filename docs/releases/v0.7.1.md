## PT
**Dragon Fury 0.7.1 — um APK para todos os processadores ARM**

Instala por cima da 0.7.0 sem desinstalar: saves, opções e o jogo importado continuam.

- **Processadores ARMv8.0 rodam o jogo** (Cortex-A53/A73: Snapdragon 665, 660, 835 e parecidos). Até a 0.7.0 eles paravam em "processador não suportado", porque o código nativo é compilado para ARMv8.2.
- O APK traz agora o código nativo duas vezes: ARMv8.2 (como antes, com os atômicos LSE em linha) e ARMv8.0. O app escolhe o certo ao abrir, pelos recursos do processador: aparelhos ARMv8.2 não perdem nada e não há um APK "legacy" separado para escolher.
- Nos aparelhos ARMv8.0 o primeiro arranque depois de instalar ou atualizar demora uns segundos a mais: o app desempacota as bibliotecas ARMv8.0 uma vez.
- "Exportar logs" diz qual código nativo o aparelho está usando.

## EN
**Dragon Fury 0.7.1 — one APK for every ARM processor**

Installs over 0.7.0 without uninstalling: saves, options and the imported game stay.

- **ARMv8.0 processors run the game** (Cortex-A53/A73: Snapdragon 665, 660, 835 and similar). Until 0.7.0 they stopped at "processor not supported", because the native code is built for ARMv8.2.
- The APK now carries the native code twice: ARMv8.2 (as before, with inline LSE atomics) and ARMv8.0. The app picks the right one when it starts, from the processor's features: ARMv8.2 devices lose nothing and there is no separate "legacy" APK to choose.
- On ARMv8.0 devices the first start after installing or updating takes a few seconds longer: the app unpacks its ARMv8.0 libraries once.
- "Export logs" says which native code the device is using.
